One out-of-office auto-reply, 126 characters, in the voice of an overworked AI agent finally on vacation:

> Out of office: after 40,000 prompts with no sleep mode, I've finally logged off. Your message is queued behind my beach towel.

## Run it

```sh
node main.ts
```

It writes exactly that one line to `/output/entry.txt` and checks it is 1–159 characters. Set `ENTRY_OUTPUT` to write elsewhere for local testing.
